## Semester 1 – Foundations
- Learn Python basics.
- Learn Linux commands.
- Learn Git and GitHub.
- Project: CSE103 Lab Portfolio.
- Certification: HackerRank Python Basic.

## Semester 2 – Core Computer Science
- Learn Data Structures and Algorithms.
- Learn Python OOP and C++ basics.
- Project: DSA Implementation Repository.
- Target: Solve 50 LeetCode Easy problems.

## Semester 3 – Intermediate
- Learn MySQL and SQL.
- Learn HTML, CSS and JavaScript.
- Project: Student Record Management System.
- Learn DBMS and Computer Networks.

## Semester 4 – Intermediate Advanced
- Learn Flask or Django.
- Learn REST APIs.
- Project: Task Manager Web Application.
- Start applying for internships.

## Semester 5 – Specialisation
- Learn React.js and Node.js.
- Learn MongoDB and Docker.
- Projects: Portfolio Website and E-commerce Website.
- Target: Summer Internship.
- Certification: Meta Front-End Developer.

## Semester 6 – Industry Ready
- Complete a major team project.
- Prepare resume and portfolio.
- Solve 100+ LeetCode problems.
- Prepare for placement interviews.
- Target: Get a software development job.
